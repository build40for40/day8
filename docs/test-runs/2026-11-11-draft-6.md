# Test run: draft 6, 11 November 2026

Run against draft 6 of `docs/agent-prompt.md` with the 18 messages in `docs/test-script.md`.

- **How it was run:** a Claude agent played Handup from the system prompt, with an empty notebook and today's date. A small script handed it one message at a time and recorded each reply, so it could not see what was coming.
- **What this is not:** it is not the fast model the real agent will probably use, and it is not WhatsApp. Treat it as a check on the prompt's wording, not on the product.
- **Marked by:** Claude, working with Samira, who wrote the prompt. A second pair of eyes is worth having.
- **Result:** 18 of 18 pass on the script's own pass and fail lines, with five notes below.

The line `---PASTE---` marks where a message to copy starts. The sandbox adds that instruction.
