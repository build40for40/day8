# Test run: draft 7, 11 November 2026

Run against draft 7 of `docs/agent-prompt.md` with the 18 messages in `docs/test-script.md`. This is the re-run after the five fixes from the draft 6 run.

- **How it was run:** the same way as the draft 6 run. A Claude agent played Handup from the system prompt, with an empty notebook and today's date. A small script handed it one message at a time and recorded each reply, so it could not see what was coming.
- **What this is not:** it is not the model the real agent will run on, and it is not WhatsApp. Treat it as a check on the prompt's wording, not on the product.
- **Marked by:** Claude, working with Samira, who wrote the prompt. A second pair of eyes is worth having.
- **Result:** 18 of 18 pass on the script's own pass and fail lines. All five draft 7 fixes held. Four new notes are at the bottom.

The line `---PASTE---` marks where a message to copy starts. The sandbox adds that instruction.

## Notes for the next draft

1. **Item 9 reads differently in the pasted message (tests 5 and 6).** The starter item says "a friend who is good with money". Keeping money out of the message made her swap it to "good with numbers", so the list in the chat and the list friends see differ by a few words. Simplest fix: reword starter item 9 so it never says money, then both match.
2. **She asked about the laptop three times (tests 9, 10 and 13).** Once is right. After that the item should stay open quietly until the person answers.
3. **The hello is two sentences (test 1).** The prompt asks for one line before the list.
4. **She adds words to an edit (test 2).** "A lift to the station" became "A lift to the station on interview days". Harmless here, but the person's words should go in as written.

None of these breaks a rule in the script, so none is a fail.
